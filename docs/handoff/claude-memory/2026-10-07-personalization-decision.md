2026-10-07 討論但還沒動工的方向：讓系統「認識使用者」，新使用者沒有歷史資料時先套用
「跟他目前言行最像的一群人」的預設值（cold-start），之後每次他的真實選擇偏離預設，就把
預設值往他個人的方向校正（這是推薦系統的標準做法：population prior + 貝氏校正）。

**已經確定的技術決策（不用再重新討論）**：
- **不新增模型**：這台機器 6GB VRAM 已經同時跑 Qwen2.5-3B(GPU)+1.5B(CPU)，裝不下第三顆。
  更重要的是，這個任務本質上不需要生成式模型——分群判斷是統計最近鄰比對、記憶是既有
  `rag/retriever.py` 的檢索架構、校正是加權平均，三步都是純邏輯/數學，不是生成任務。
  唯一會用到模型的地方是最後生成部署 spec 那步，直接用現有 3B 的 `/infer` + RAG few-shot
  機制，把使用者自己的歷史偏好當額外 few-shot 範例注入即可，不需要新管線。
- **分類步驟不能丟給 LLM 自由判斷**：要用可解釋的統計相似度（比對副本數/資源設定跟幾個
  典型族群的距離），不是又讓模型自己猜「這個人比較像哪一種人」——跟這整個 session 一路在
  修的「不能信任模型自報判斷，要有確定性查核」是同一個原則，見
  [[2026-10-07-admin-identity-and-residual-fixes]]。
- **資料集不是去找「使用者行為人格分類」這種現成資料集**（查過，這種東西太特定了，大概率
  不存在）。正確做法是自己從公開的 K8s manifest/Helm chart 語料（GitHub 上大量公開的部署
  設定檔）用統計方式分出幾個典型「風格」（保守型/生產環境、寬鬆型/實驗用、極簡型/新手），
  這部分**還沒有真的去查證有沒有可用的公開語料**，是下次要做的第一步。

**Why**：使用者明確問過「要不要為此新增一個模型」，答案是否定的，理由記在這裡避免
之後又被重新提出來討論一樣的問題。

**How to apply**：下次要做這個功能時，順序是：(1) 先查證有沒有可用的公開 K8s 部署語料
可以拿來統計分群，查到什麼/查不到什麼都要老實回報；(2) 分群完成後設計「新使用者 → 比對
最近鄰族群 → 套用族群預設值」的確定性比對邏輯；(3) 累積使用者自己的真實部署紀錄後，用
加權平均逐漸把預設值校正到個人化，權重隨累積次數增加往個人靠。整個功能屬於新子系統，
規模上要走 Plan Mode，不要跳過直接動工。

**環境備註**：使用者準備組裝新電腦，這次之後的 session 可能換了硬體環境，之前「6GB VRAM
撐不住第三顆模型」這個硬體限制的前提，到時候可能不成立了，要重新確認目前的硬體規格再判斷。

**2026-10-07 同日稍晚，重新定位成「續訂留存機制」，不是單純的個人化體驗**：

使用者挑戰過「這些防護力都不足以讓客戶多花錢續訂」，討論出來的結論是：真正驅動續訂的
不是「好玩」或「更安全」，是「用得越久、累積的東西越多、換掉的代價越高」。這個「認識你」
功能重新定位成這個邏輯下的核心建設，具體落地方向是**讓 Chat 統一入口變成使用者自己基礎
設施唯一的累積記憶庫**——現在系統裡所有「這個使用者的叢集發生過什麼事」的資訊都是用完
即丟的（Healer `recent_actions` 只留最近幾筆、部署歷史/使用者偏好完全沒有持久化），
存下來之後 Chat 能做到三件事（比單純的「記住部署偏好」範圍更大，是同一個方向往產品化
再推一步）：
1. **操作歷史問答**：「上次 X 服務掛掉是什麼原因？」「我這個月改了幾次 Y 的設定？」——
   答案是只有這個平台自己長期累積才拿得出來的，連 Claude Code 這種每次從零開始的工具
   都做不到（這是跟 [[2026-10-07-large-qa-sweep-and-fixes]] 同一天討論出的「系統 vs
   直接叫 Claude 做」價值定位延伸）。
2. **主動簡報**：打開 Chat 時，如果上次登入後發生過值得注意的事，系統主動先講，不用
   使用者自己想到要問。
3. **個人化預設值**：這份記憶原本討論的「cold-start + 校正」機制。

**Why**：訂閱制軟體的續訂驅動力標準邏輯——累積的歷史資料換平台就沒了，才是真正的
switching cost，不是功能好不好玩。

**How to apply**：下次動工時，技術路徑不變（仍然是不新增模型、用統計/規則+既有 RAG
架構），但要先做「持久化 Healer 診斷紀錄 + 部署歷史，讓 Chat 能查詢」這個資料層，
範圍最小、立刻有感，之後再疊加主動簡報跟個人化預設值。
